Vorleser

Macht aus jedem Text ein Hörbuch. EPUB, PDF oder einfach eingefügter Text, vorgelesen mit natürlichen Stimmen. Kostenlos und ohne Konto.

macOS

Mac mit Apple-Chip (M1 oder neuer), macOS 12+

Für Mac laden

Windows

Windows 10 oder 11, 64 Bit

Für Windows laden

Was er kann

  • Liest EPUB, PDF, Text, Markdown und HTML vor
  • Natürliche Stimmen auf Deutsch und Englisch
  • Merkt sich die Stelle, an der du aufgehört hast
  • Kapitelmenü und Mitlesen Wort für Wort
  • Export als Hörbuch (M4B, MP3, WAV)
  • Diktieren statt tippen
  • Optional: Texte mit der eigenen Stimme vorlesen
  • Ohne Internet liest eine Offline-Stimme weiter

Installieren

Der Vorleser ist ein privates Projekt und nicht bei Apple oder Microsoft registriert. Dein System warnt deshalb beim ersten Start einmal.

Mac
  1. Die .dmg öffnen und Vorleser in den Ordner Programme ziehen.
  2. Vorleser starten. Erscheint „Vorleser wurde nicht geöffnet“, auf Fertig klicken.
  3. Systemeinstellungen › Datenschutz & Sicherheit öffnen, ganz nach unten scrollen und bei Vorleser auf Dennoch öffnen klicken.

Alternativ im Terminal: xattr -cr /Applications/Vorleser.app

Windows
  1. Die Vorleser-windows-setup.exe doppelklicken. Administratorrechte sind nicht nötig.
  2. Erscheint „Der Computer wurde durch Windows geschützt“: Weitere Informationen, dann Trotzdem ausführen.
Eigene Stimme

Die Funktion „eigene Stimme“ ist nicht im Download enthalten (ca. 4,5 GB). Sie lässt sich in der App unter Einstellungen › Stimmen nachinstallieren. Am Mac nutzt sie den Grafikchip, unter Windows eine NVIDIA-Grafikkarte. Ohne Grafikkarte funktioniert sie, ist aber sehr langsam.
